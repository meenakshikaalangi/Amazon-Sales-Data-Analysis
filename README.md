# Amazon-Sales-Data-Analysis
# INTRODUCTION
The Amazon Sales Report is based on a dataset of over 1.2 lakh transactions containing
details such as order status, category, size, fulfillment type, shipping service, and revenue.
Using Python libraries like Pandas, NumPy, Matplotlib, and Seaborn, the data was cleaned and
analyzed to uncover customer preferences, product demand, and regional sales patterns.
This study provides insights into overall sales performance and business growth opportunities.
# PROBLEM STATEMENT
E-commerce platforms like Amazon generate massive volumes of raw sales data,
which by itself does not provide meaningful insights. The problem is to analyze
this data to evaluate sales performance across product categories, regions, and time periods.
Key questions include: Which categories generate the most revenue? Which states and
cities contribute most to sales? What are customer size and shipping preferences?
How do B2B and B2C sales compare? The aim is to convert raw data into actionable insights for decision-making.
# MOTIVE
The main motive of this project is to:
Identify high-performing and underperforming product categories.
Understand demand based on product sizes and shipping choices.
Compare fulfillment methods between Amazon and merchants.
Examine the share of B2B versus B2C orders.
Detect seasonal and regional sales trends.
These insights can guide strategies to optimize inventory, reduce cancellations, and boost revenue growth.
